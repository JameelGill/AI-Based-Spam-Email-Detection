
# AI-Based Spam Email Detection System

An AI-based system that detects spam and normal emails using Machine Learning and Python.

## Features

- Spam and Ham Email Classification
- Text Preprocessing
- Machine Learning Model
- Prediction Confidence
- Email Detection History
- CSV History Download
- Streamlit User Interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Model Performance

Accuracy: 98.83%

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
